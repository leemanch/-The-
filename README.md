# Оценки The БЫК

Мобильный сайт для оценки блюд по вкусу и внешнему виду. Друзья выбирают блюда из меню, выставляют баллы от 1 до 10 и публикуют комментарии. Публичную ленту можно читать без регистрации.

## Запуск на Linux AMD64

С установленным Docker и Compose выполните в каталоге клонированного репозитория:

```sh
docker load -i the-byk-linux-amd64.tar
cd byk
docker compose up -d --no-build
curl -fsS http://127.0.0.1:28741/health
```

Ответ `ok` означает, что приложение запущено. Для сборки из исходников перейдите в `byk` и выполните `docker compose up -d --build`.
